Độ phức tạp

Dựng cây Huffman: O(n log n) với heap

T(n) = O(n) + (n − 1) · 3 · O(log n) = O(n log n)

Heap nhị phân

O(n log n)

n − 1 lần: 2 EXTRACT-MIN và 1 INSERT, mỗi thao tác O(log n)

Hai hàng đợi

O(n log n)

Sắp xếp một lần, phần gộp chỉ O(n); nếu tần suất đã sắp sẵn thì O(n)

Quét tuyến tính

O(n²)

Mỗi bước tìm hai phần tử nhỏ nhất bằng cách duyệt danh sách, tốn O(n)

Nén toàn bộ dữ liệu N byte: O(N + n log n). Bảng byte có n ≤ 256 nên phần O(N) chiếm ưu thế.

Nhóm 8 · Thuật toán nâng cao

Cormen và cs., mục 16.3

Khởi tạo heap tốn O(n). Vòng lặp chạy đúng n trừ 1 lần, mỗi lần gồm hai thao tác lấy phần tử nhỏ nhất và một thao tác chèn, mỗi thao tác O(log n). Tổng là O(n log n). Nhóm cài đặt thêm hai cách khác của cùng phép chọn tham lam để đối chiếu: cách quét tuyến tính O(n bình phương) và cách dùng hai hàng đợi. Với bảng chữ cái byte thì n tối đa 256, nên chi phí chủ yếu là phần tuyến tính theo độ dài dữ liệu.
